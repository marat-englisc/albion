# Справочник — Все типы условных предложений

> [!abstract] Как выбрать
> Два вопроса: **условие реальное или воображаемое? К какому времени относятся условие и результат: настоящему, будущему или прошлому?**

## Основные модели

| Ситуация | Пример |
| --- | --- |
| [[059 - Zero Conditional — общие закономерности\|Zero: обычный результат]] | **If you heat ice, it melts.** — Если нагреть лёд, он тает. |
| [[060 - First Conditional — реальное будущее условие\|First: возможное будущее]] | **If it rains, we'll stay home.** — Если будет дождь, мы останемся дома. |
| [[061 - Second Conditional — воображаемое настоящее и будущее\|Second: воображаемое сейчас/потом]] | **If I had a car, I'd drive.** — Если бы у меня была машина, я бы поехал на ней. |
| [[062 - Third Conditional — другое прошлое\|Third: другое прошлое]] | **If I'd known, I'd have come.** — Если бы я тогда знал, я бы пришёл. |
| [[063 - Mixed Conditionals — разные времена условия и результата\|Mixed: прошлое → сейчас]] | **If I'd slept more, I wouldn't be tired now.** — Если бы я поспал дольше, сейчас не был бы уставшим. |
| [[063 - Mixed Conditionals — разные времена условия и результата\|Mixed: общая черта → прошлое]] | **If I spoke French, I'd have understood him.** — Если бы я знал французский, то понял бы его тогда. |

## Вместо if

| Выражение | Значение |
| --- | --- |
| unless | если не |
| as long as / provided that | при условии |
| even if | даже если |
| in case | заранее на случай, если |
| but for + существительное | если бы не |
| otherwise | иначе |

**Had I known… = If I had known…**. **Were I you… = If I were you…**. **Should you need help…** — если вдруг понадобится помощь.

> [!warning] Не смешивай смыслы
> **Take my number in case you need help** — возьми сейчас. **Call me if you need help** — позвони, когда понадобится. В обычном будущем условии — настоящее, но не любое `if` вводит условие: **I don't know if he will come** — «не знаю, придёт ли».

## Желания и предпочтения

- **I wish I knew / If only I knew** — жаль, что сейчас не знаю.
- **I wish I'd known** — жаль, что тогда не знал.
- **It's time we left** — пора уходить сейчас.
- **I'd rather you stayed** — предпочёл бы, чтобы ты остался.
