# Справочник — Неправильные глаголы

> [!abstract] Как пользоваться
> **V** — начальная форма без `to`. **V2** — форма простого прошедшего времени (Past Simple). **V3** — третья форма, используемая в Perfect и пассивном залоге. Например: **go → went → gone**. Варианты через `/` проверяй по значению и варианту языка.

Группы ниже выделены по основным британским формам. Буквы A, B и C показывают, совпадают ли формы между собой; произношение у одинаково написанных форм иногда различается.

## Группа 1. Все три формы одинаковые (A — A — A)

| V → V2 → V3 | Значение |
| --- | --- |
| **bet** → bet → bet | держать пари |
| **cost** → cost → cost | стоить |
| **cut** → cut → cut | резать |
| **hit** → hit → hit | ударять |
| **hurt** → hurt → hurt | ранить, болеть |
| **let** → let → let | позволять |
| **put** → put → put | класть |
| **quit** → quit → quit | бросать, уходить |
| **set** → set → set | устанавливать |
| **shut** → shut → shut | закрывать |
| **spread** → spread → spread | распространять |
| **read** → read /red/ → read /red/ | читать (пишется одинаково, звучит по-разному) |

## Группа 4. V3 совпадает с V (A — B — A)

| V → V2 → V3 | Значение |
| --- | --- |
| **become** → became → become | становиться |
| **come** → came → come | приходить |
| **run** → ran → run | бежать |

## Группа 5. Начальная и прошедшая формы совпадают (A — A — B)

| V → V2 → V3 | Значение |
| --- | --- |
| **beat** → beat → beaten | бить, побеждать |

## Не перепутай

- **Read** пишется одинаково; V — /riːd/, V2/V3 — /red/.
- **Lie → lay → lain** — лежать. **Lay → laid → laid** — класть. **Lie → lied → lied** — лгать.
- **Go → went → gone**, но **be → was/were → been**.
- **Be born** — «родиться»: **I was born in May**. В других значениях `bear` обычно имеет третью форму **borne**: **The costs were borne by the company** — «Расходы взяла на себя компания».
- **Hang → hung → hung** — «вешать». В значении «казнить через повешение» обычно **hanged → hanged**.
- **Shine → shone → shone** — «светить». В значении «начищать до блеска» обычно **shined → shined**.
- **Get → got → got** в BrE; в AmE для получения/изменения часто **gotten**. Обладание: **have got**, без `gotten`.
