# Albion Telegram Bot

Бот для изучения английского на TypeScript, grammY, Prisma ORM 7 и SQLite. Интервальные повторения рассчитываются `ts-fsrs` 5.4.2 (алгоритм FSRS-6). Интерфейс — на русском.

## Быстрый запуск

Нужен Node.js 24 LTS. Выполняйте команды из папки `Bot`.

```powershell
npm ci
Copy-Item .env.example .env
```

Создайте бота через [@BotFather](https://t.me/BotFather) и впишите его токен в `BOT_TOKEN` в `.env`. Токен хранится локально и исключён из Git.

```powershell
npm run setup
npm run build
npm start
```

`setup` генерирует Prisma Client, применяет миграции и импортирует материалы. Для текущих исходников это 7 603 карточки, 144 урока, 5 справочников и 1 658 упражнений. После запуска откройте своего бота в Telegram и отправьте `/start`.

Бот работает через long polling: публичный домен и HTTPS-сервер не требуются. Нужен доступ к Telegram API. Запускайте один процесс на токен и базу. Для разработки: `npm run dev`.

## Обучение

- Пять наборов: слова, идиомы, фразовые глаголы, неправильные глаголы и коллокации.
- Карточки с переводом, IPA, английским определением, примерами и примечаниями. Для неправильных глаголов показываются все три формы.
- Четыре оценки FSRS с предварительным интервалом на кнопке. Ответ нужно открыть перед оценкой. Повторное нажатие не записывает вторую оценку.
- EN → RU и RU → EN имеют отдельные состояния памяти. В обратном направлении английский ответ и озвучка доступны после раскрытия.
- Новые карточки ограничены общим дневным лимитом. Повторения, срок которых наступил, доступны независимо от лимита. Повторения имеют приоритет перед новыми карточками.
- Сессия сохраняется в SQLite. `/study` продолжает открытую карточку после перезапуска. Время ожидания следующего повторения показано после завершения очереди.
- `/undo` отменяет последнюю доступную оценку и восстанавливает предыдущее расписание.
- Карточку можно отложить. Возврат отложенных карточек находится в настройках и сохраняет расписание.
- Доступны выбор CEFR, дневной лимит 0–200, удержание 85/90/95%, автоматическая озвучка и часовой пояс IANA. Дневные границы и серия занятий учитывают часовой пояс пользователя.
- Озвучка берётся из `audio/`. Бот сопоставляет имена с терминами, учитывает `read (past)`, омонимы и варианты произношения. Для неправильного глагола после раскрытия отправляются записи форм. Загруженные файлы повторно отправляются по Telegram `file_id`; изменение локального файла обновляет кэш.

Если ответ забыт, ставьте **«Снова»**. «Трудно» означает, что ответ удалось вспомнить. Обучение FSRS-параметров на личной истории не реализовано: используются стандартные параметры FSRS-6 и выбранное удержание.

## Грамматика

Уроки читаются из Markdown вместе с YAML-метаданными. Сохраняются выделения, ссылки, примеры и содержимое таблиц. Obsidian-ссылки преобразуются в текст, callout-блоки — в обычные разделы. Длинные уроки разбиваются на страницы с сохранением позиции. Ответы самопроверки открываются отдельной кнопкой. Уроки можно отмечать пройденными, фильтровать по CEFR и искать по названию или ключевым словам. Пять справочников доступны отдельной кнопкой.

Упражнения из `grammar_tasks.xlsx` связаны с номерами уроков. Поддерживаются кнопки с вариантами и ввод текста. Проверка учитывает регистр, пробелы, конечную пунктуацию, тип апострофа, некоторые сокращения и допустимые варианты из исходного файла. Для нескольких пропусков вводите части через `/`, например `Have / tried`. Варианты ответа на один пропуск разделяются `/`; варианты полного набора ответов — новой строкой или `|`. Текст проверяется по допустимым ответам, без LLM и оценки свободного пересказа.

Сначала предлагаются ещё не решённые упражнения, затем ошибки, затем давно решённые. Просмотр готового решения записывается как ошибка. Статистика показывает результаты практики, серию занятий, повторения и пройденные уроки.

## Материалы и повторный импорт

По умолчанию `CONTENT_ROOT=./content` указывает на материалы внутри папки бота. Папку `Bot` можно переносить и запускать отдельно от остального репозитория:

```text
Bot/
  content/
    collections/
      words.xlsx
      idiomas.xlsx
      phrasal_verbs.xlsx
      irregular_verbs.xlsx
      collocations.xlsx
      grammar_tasks.xlsx
    audio/
      words/  idiomas/  phrasal_verbs/  irregular_verbs/  collocations/
    grammar/
      001 - ...md
      ...
      Справочник — ...md
```

Excel-файлы читаются с первого листа, колонки определяются по существующим заголовкам. Порядок колонок, кроме первой колонки с термином, можно менять. Исходники не изменяются. Служебные комментарии и рисунки Excel не участвуют в импорте. Для словарных карточек обязательны термин, английское определение и русский перевод. Отсутствие аудио выдаёт предупреждение, но не мешает обучению.

После обновления файлов в `Bot/content`:

```powershell
npm run content:check
npm run content:import
```

Все файлы проверяются до записи. Затем импорт выполняется одной транзакцией. Удалённые материалы архивируются, их история сохраняется; при возвращении того же материала прогресс восстанавливается. Повторный импорт не меняет FSRS-состояния. Идентичность словарной карточки определяется набором, термином, частью речи и английским определением: исправления перевода, примеров, IPA и аудио сохраняют прогресс; изменение термина или смысла создаёт новую карточку. Упражнения используют `№`, уроки — номер в имени, справочники — стабильный хеш имени файла. Не переиспользуйте старые номера для других уроков или заданий.

Не запускайте импорт одновременно с занятиями: остановите процесс, импортируйте изменения и снова запустите. Открытые карточки и прогресс останутся в базе.

## Конфигурация и данные

Смотрите `.env.example`. Относительные пути `DATABASE_URL` и `CONTENT_ROOT` вычисляются от папки `Bot`.

`ALLOWED_USER_IDS=123456789,987654321` ограничивает доступ указанными Telegram ID. При пустом значении бот доступен любому пользователю в личных сообщениях. Групповые занятия не поддерживаются. У каждого пользователя отдельные карточки, настройки и прогресс.

База по умолчанию: `Bot/data/albion.db`. Она, журналы SQLite, `.env`, зависимости и сгенерированный клиент исключены из Git. Для резервной копии остановите бота и скопируйте каталог `data` целиком. Для просмотра базы: `npm run db:studio`.

## Проверка

```powershell
npm run check
npm test
npm run build
```

Тесты используют отдельные временные SQLite-базы и имитацию Telegram API. Проверяются повторения, лимиты, отмена, изоляция пользователей, импорт и архивирование, направления, сценарии Telegram, упражнения, все исходные карточки, форматирование всех уроков и наличие аудио. Тесты материалов читают `Bot/content`; тестовые учётные записи в рабочую базу не попадают.

## Docker

Из папки `Bot`, после заполнения `.env`:

```powershell
docker compose up --build -d
docker compose logs -f
```

Docker собирает образ из папки `Bot`, включая `content`. База хранится в локальной папке `Bot/data`. При старте контейнер применяет миграции и повторяет импорт. После изменения материалов в `content` пересоберите образ. Остановка: `docker compose down`. Удаление контейнера не удаляет локальную базу.

Конфигурация Docker подготовлена, но сборка контейнера в этой среде не проверялась: Docker здесь не установлен. Локальные установка, миграции, импорт, тесты и сборка Node.js проверены.

## Устройство проекта

`src/content` читает Excel, Markdown и аудио. `src/services` содержит FSRS, очередь, упражнения и статистику. `src/bot` отвечает за интерфейс grammY. `prisma` хранит схему и начальную миграцию. Изменения Android-приложения для работы бота не требуются.

Официальная документация: [grammY](https://grammy.dev/guide/), [Prisma SQLite](https://www.prisma.io/docs/v7/prisma-orm/quickstart/sqlite), [ts-fsrs 5.4.2](https://github.com/open-spaced-repetition/ts-fsrs/tree/v5.4.2).
