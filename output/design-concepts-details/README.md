# Albion — английский характер через небольшие UI-детали

Вторая серия концептов, основанная на выбранных пользователем деталях конверта и почтового штемпеля. В каждой картинке — два экрана и отдельная колонка элементов. Изображения созданы встроенным ImageGen; полный набор запросов сохранён в [prompts.json](C:/Users/Marat/Desktop/albion/output/design-concepts-details/prompts.json).

1. **Private Correspondence** — клапан конверта, небольшая печать с A, почтовый штемпель, марка уровня, загнутый угол и пунктирный разделитель.

![Private Correspondence](C:/Users/Marat/Desktop/albion/output/design-concepts-details/01-private-correspondence.png)

2. **The English Ticket** — билетные выемки, отрывной корешок с числом заданий, бирка уровня, отметки прохождения и штамп завершения.

![The English Ticket](C:/Users/Marat/Desktop/albion/output/design-concepts-details/02-english-ticket.png)

3. **Private Members’ Edition** — тёмная версия, монограмма, рамка клубной карточки, ленточная закладка, небольшой London-штемпель и тонкие золотые линейки.

![Private Members’ Edition](C:/Users/Marat/Desktop/albion/output/design-concepts-details/03-private-members-edition.png)

4. **The London Reading Room** — полоска книжного корешка, двойная рамка, каталожный ярлык, библиотечный штамп, колонтитулы, римская нумерация и типографская буквица.

![The London Reading Room](C:/Users/Marat/Desktop/albion/output/design-concepts-details/04-london-reading-room.png)
