# Some, any и no

> [!abstract] Коротко
> **Some — некоторое количество. Any — какое-либо или любое. No — никакого.**

| Обычная ситуация | Пример |
| --- | --- |
| утверждение | We have some milk. |
| вопрос | Have you got any milk? |
| отрицание | We haven't got any milk. |
| отсутствие с положительным глаголом | We have no milk. |

## Примеры

- **Would you like some tea?** — Чаю? В предложениях и просьбах часто `some`.
- **Can I have some water?** — Можно воды?
- **Choose any book.** — Выбери любую книгу: `any` бывает в утверждении.

> [!warning] Не два отрицания
> **There is no milk / There isn't any milk**. В значении неопределённого количества `some/any` обычно употребляются с исчисляемыми существительными во множественном числе и с неисчисляемыми. `Any` в значении «любой» бывает и с единственным числом: **any book**. `Some` тоже может стоять перед единственным числом в других значениях: **some day** — «когда-нибудь».

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Вставь some или any: There are ___ biscuits in the box.
2. Вставь some или any: Have you got ___ brothers?
3. Вставь some или any: Could I have ___ water, please?
4. Вставь some или any со значением «в любое время»: You can call me ___ time.
5. Перефразируй с no: *We don't have any milk.*
6. Исправь ошибку: *I didn't buy no bread.*

> [!success]- Ответы и пояснения
> 1. **some** — утверждение.
> 2. **any** — нейтральный вопрос.
> 3. **some** — просьба, ждём «да».
> 4. **any** — «в любое время».
> 5. **We have no milk.** — `no` = `not any`.
> 6. **I didn't buy any bread. / I bought no bread.** — одно отрицание.
