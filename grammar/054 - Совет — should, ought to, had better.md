# Совет — should, ought to, had better

> [!abstract] Коротко
> **Should / ought to** — совет. **Had better** — настоятельный совет: иначе возможны неприятные последствия.

| Положительно | Отрицательно |
| --- | --- |
| should go | shouldn't go |
| ought to go | ought not to go |
| had better go | had better not go |

## Примеры

- **You should get some rest.** — Тебе стоит отдохнуть.
- **Should I call her?** — Мне стоит ей позвонить?
- **You'd better leave now or you'll miss the train.** — Лучше уходи сейчас, иначе опоздаешь.

> [!warning] Had не означает прошлое
> **You'd better go now = you had better go now**. После `better` нет `to`. `Should` может выражать и ожидание: **The parcel should arrive today**.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Вставь should/ought to/had better: You look tired. You ___ go to bed earlier.
2. Вставь: It's going to rain. We'd better ___ (take) umbrellas.
3. Сделай отрицание: *You had better be late.*
4. Вставь to или ничего: You ought ___ apologise.
5. Сделай вопрос: *I should call her.*
6. Исправь ошибку: *You should to see a doctor.*

> [!success]- Ответы и пояснения
> 1. **should / ought to / had better** — `should/ought to` дают обычный совет, `had better` звучит настойчивее; контекст не исключает ни один из вариантов.
> 2. **take** — после `had better` без `to`.
> 3. **You had better not be late. / You'd better not be late.** — `not` ставится после `better`.
> 4. **to** — в `ought to` частица обязательна.
> 5. **Should I call her?** — `should` переставляем вперёд.
> 6. **You should see a doctor.** — после `should` без `to`.
