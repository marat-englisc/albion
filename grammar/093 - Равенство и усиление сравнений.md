# Равенство и усиление сравнений

> [!abstract] Коротко
> - Равенство: `as + adj + as` — `as tall as`. Неравенство: `not as/so … as`.
> - Размер разницы: `much / far / a lot + comparative` (намного), `a bit / slightly` (немного). *very better* — ошибка.
> - «Чем…, тем…»: `the + comparative, the + comparative`. «Всё…»: `colder and colder`, `more and more difficult`.

<!-- beginner-intro:start -->
## Простыми словами

Сравнение можно настроить точнее: «такой же», «чуть лучше», «намного лучше», «всё лучше». Для равенства используется обычный признак между двумя `as`. Для разницы сначала образуй сравнительную степень, затем добавь её размер.

Не ставь сравнительную форму внутрь `as…as`: `as tall as`, не `as taller as`. Перед `better/bigger` употребляй `much/a little`, а не обычное `very`. Двойная модель `the more…, the easier…` связывает два изменения: чем больше одного, тем больше другого.

## Правило и схема
<!-- beginner-intro:end -->

Сравнения можно уточнять: одинаковая степень, небольшое или большое различие, постепенное изменение и зависимость одного изменения от другого.

| Смысл | Модель |
| --- | --- |
| Такой же | as + adj/adv + as |
| Не такой | not as/so + adj/adv + as |
| Намного | much/far/a lot + comparative |
| Немного | slightly/a little/a bit + comparative |
| Всё больше | comparative and comparative; more and more + adj |
| Чем…, тем… | the + comparative…, the + comparative… |

Для равного количества: `as much water as`, `as many books as`. `The same as` — такой же; `different from` — отличающийся.

<!-- beginner-examples:start -->
## Примеры с разбором

1. **My room is as big as yours.** — Моя комната такая же большая, как твоя.  
   **Разбор:** равенство; `big` остаётся обычной формой между `as`.
2. **This route is much faster.** — Этот маршрут намного быстрее.  
   **Разбор:** `faster` уже сравнение; `much` показывает большую разницу.
3. **It's getting colder and colder.** — Становится всё холоднее.  
   **Разбор:** повтор сравнительной формы показывает постепенное изменение.
4. **The earlier we leave, the sooner we'll arrive.** — Чем раньше выедем, тем скорее приедем.  
   **Разбор:** две сравнительные части выражают зависимость результата от первого изменения.
<!-- beginner-examples:end -->

## Дополнительные примеры

- **This bag is almost as heavy as that one.** — Эта сумка почти такая же тяжёлая, как та.
- **The new route is much shorter.** — Новый маршрут намного короче.
- **The more you practise, the easier it gets.** — Чем больше практикуешься, тем легче становится.

> [!warning] Частая ошибка
> **Much better**, а не *very better*. **As good as**, а не *as better as*.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Вставь: My bag is ___ (heavy) as yours.
2. Исправь ошибку: *This phone is very better than my old one.*
3. Переведи: «Чем больше ты читаешь, тем больше знаешь».
4. Переведи: «Становится всё темнее».
5. Перефразируй: *Anna is taller than Kate.* → Kate isn't ___
6. Исправь ошибку: *He is as clever like his father.*

> [!success]- Ответы и пояснения
> 1. **as heavy** — равенство: `as + adj + as`.
> 2. **This phone is much better than my old one.** — перед сравнительной степенью — `much`, не `very`.
> 3. **The more you read, the more you know.** — модель `the more…, the more…`.
> 4. **It's getting darker and darker.** — повтор сравнительной формы.
> 5. **Kate isn't as tall as Anna.** — неравенство через `not as … as`.
> 6. **He is as clever as his father.** — оба элемента — `as`.
