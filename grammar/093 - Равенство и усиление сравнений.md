# Равенство и усиление сравнений

> [!abstract] Коротко
> **As…as — такой же. Much bigger — намного больше. A bit bigger — немного больше.**

| Смысл | Модель |
| --- | --- |
| равенство | as + прилагательное или наречие в обычной форме + as |
| не такой | not as/so + признак + as |
| большое различие | much / far / a lot + сравнительная форма |
| небольшое различие | slightly / a little / a bit + сравнительная форма |
| постепенное изменение | bigger and bigger / more and more useful |
| зависимость | the more…, the better… |

## Примеры

- **She's as tall as me.** — Она такого же роста, как я.
- **I have as many books as you.** — Столько же книг. Для неисчисляемого: **as much time as**.
- **The earlier we leave, the better.** — Чем раньше выйдем, тем лучше.

Для количества: **as many + исчисляемое существительное во множественном числе + as** и **as much + неисчисляемое существительное + as**.

**The same as** — такой же; **different from** — отличающийся. **Much better**, без *very better*.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Вставь: My bag is ___ (heavy) as yours.
2. Исправь ошибку: *This phone is very better than my old one.*
3. Переведи: «Чем больше ты читаешь, тем больше знаешь».
4. Переведи: «Становится всё темнее».
5. Перефразируй: *Anna is taller than Kate.* → Kate isn't ___
6. Исправь ошибку: *He is as clever like his father.*

> [!success]- Ответы и пояснения
> 1. **as heavy** — равенство: `as + прилагательное + as`.
> 2. **This phone is much better than my old one.** — перед сравнительной степенью — `much`, не `very`.
> 3. **The more you read, the more you know.** — модель `the more…, the more…`.
> 4. **It's getting darker and darker.** — повтор сравнительной формы.
> 5. **Kate isn't as tall as Anna. / Kate isn't so tall as Anna.** — неравенство через `not as … as`.
> 6. **He is as clever as his father.** — оба элемента — `as`.
