# Be used to и get used to — привыкнуть

> [!abstract] Коротко
> **Be used to** — уже привык. **Get used to** — привыкаю. После `to` здесь ставится **существительное, местоимение или глагол с окончанием -ing**: **the noise**, **it**, **working**.

## Примеры

- **I'm used to the noise.** — Я привык к шуму.
- **I'm used to waking up early.** — Я привык рано вставать.
- **I'm getting used to driving on the left.** — Привыкаю к левостороннему движению.
- **You'll get used to it.** — Ты к этому привыкнешь.

Время меняется у **be/get**: `was used to`, `got used to`, `will get used to`.

> [!warning] Три разные модели
> **I used to work at night** — раньше работал. **I'm used to working at night** — привык работать. **I'm getting used to working at night** — привыкаю.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Вставь глагол: I'm used to ___ (wake) up early.
2. Выбери: It took me months to (be / get) used to the climate.
3. Выбери: Don't worry, she (is used to / used to) working at night.
4. Выбери: I (used to / am used to) drink milk, but now I don't.
5. Исправь ошибку: *He isn't used to speak English.*
6. Переведи: «Ты к этому привыкнешь».

> [!success]- Ответы и пояснения
> 1. **waking** — после предлога `to` нужна форма `-ing`.
> 2. **get** — процесс привыкания.
> 3. **is used to** — ей это привычно сейчас.
> 4. **used to** — прошлая привычка, которой больше нет.
> 5. **He isn't used to speaking English.** — после `be used to` — `-ing`.
> 6. **You'll get used to it.** — будущее привыкание — `will get used to`.
