# Be used to и get used to — привыкнуть

> [!abstract] Коротко
> - `be used to + N / V-ing` — **привык**, мне это нормально: `I'm used to the noise`.
> - `get used to + N / V-ing` — **привыкаю / привыкну**: `You'll get used to it`.
> - Здесь `to` — предлог, поэтому дальше `-ing`: `used to working`. Не путай с `used to work` (раньше работал).

<!-- beginner-intro:start -->
## Простыми словами

`Be used to` означает «для меня это уже нормально». `Get used to` — «это становится для меня нормальным». Например, сначала ранний подъём неприятен, затем ты привыкаешь, а потом он больше не удивляет.

Не путай с воспоминаниями `I used to work`: там «раньше работал». Здесь есть `be/get`, а после `to` идёт вещь или действие с `-ing`: `used to the noise`, `used to working`. Время меняется у `be/get`, а не у слова `used`.

## Правило и схема
<!-- beginner-intro:end -->

`Be used to` означает «быть привыкшим», `get used to` — «привыкать, привыкнуть». Здесь `to` — **предлог**, поэтому дальше нужно существительное, местоимение или `V-ing`.

## Схемы

- `S + be used to + N / V-ing` — привычная ситуация.
- `S + get used to + N / V-ing` — процесс привыкания.

Время меняется у `be/get`: `was used to`, `am getting used to`, `will get used to`. Это отличается от `used to + V`, которое описывает прошлое: [[031 - Used to и would — прошлые привычки|Used to и would — прошлые привычки]].

<!-- beginner-examples:start -->
## Примеры с разбором

1. **I'm used to the noise.** — Я привык к шуму.  
   **Разбор:** шум уже воспринимается как обычная часть жизни. После `to` — существительное.
2. **I'm getting used to driving on the left.** — Я привыкаю к левостороннему движению.  
   **Разбор:** привыкание ещё идёт. После предлога `to` действие оформлено как `driving`.
3. **You'll get used to it.** — Ты к этому привыкнешь.  
   **Разбор:** будущее выражено через `will get`; `it` заменяет уже названную ситуацию.
4. **I used to get up late, but now I'm used to getting up early.** — Раньше я вставал поздно, а теперь привык вставать рано.  
   **Разбор:** сначала прошлая привычка `used to + V`, затем нынешняя привычность `am used to + V-ing`.
<!-- beginner-examples:end -->

## Дополнительные примеры

- **I'm used to working alone.** — Я привык работать один.
- **She's getting used to her new job.** — Она привыкает к новой работе.
- **We weren't used to the cold.** — Мы не привыкли к холоду.

> [!warning] Частая ошибка
> **I'm used to getting up early**, а не *I'm used to get up early*.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Вставь глагол: I'm used to ___ (wake) up early.
2. Выбери: It took me months to (be / get) used to the climate.
3. Выбери: Don't worry, she (is used to / used to) working at night.
4. Выбери: I (used to / am used to) drink milk, but now I don't.
5. Исправь ошибку: *He isn't used to speak English.*
6. Переведи: «Ты к этому привыкнешь».

> [!success]- Ответы и пояснения
> 1. **waking** — после предлога `to` нужна форма `-ing`.
> 2. **get** — процесс привыкания.
> 3. **is used to** — ей это привычно сейчас.
> 4. **used to** — прошлая привычка, которой больше нет.
> 5. **He isn't used to speaking English.** — после `be used to` — `-ing`.
> 6. **You'll get used to it.** — будущее привыкание — `will get used to`.
