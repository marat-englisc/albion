# Be used to и get used to — привыкнуть

> [!abstract] Коротко
> **I'm used to it** — я **привык** (уже). **I'm getting used to it** — я **привыкаю** (сейчас). После этих фраз — вещь или глагол с **-ing**.

## Суть

Это не то же самое, что **used to** из прошлого урока! Сравни три похожие фразы:

| Фраза | Значит |
| --- | --- |
| I **used to** work at night. | **Раньше** я работал ночью (теперь нет). |
| I'**m used to** working at night. | Я **привык** работать ночью. |
| I'**m getting used to** working at night. | Я **привыкаю** работать ночью. |

Разница в маленьком слове **be** (am / is / are) или **get** перед **used to**:

- **be used to** — состояние: уже привык, мне это нормально.
- **get used to** — процесс: становится привычным.

> [!example] Формула
> **be / get used to** + **вещь**: I'm used to **the noise**.
>
> **be / get used to** + **глагол-ing**: I'm used to **waking** up early.

Здесь **to** — не часть глагола, а предлог «к» (привык **к** чему?). Поэтому после него **-ing**, а не начальная форма.

## Примеры

- **I'm used to the noise.** — Я привык к шуму.
- **I'm used to waking up early.** — Я привык рано вставать.
- **I'm getting used to driving on the left.** — Привыкаю к левостороннему движению.
- **It took me months to get used to the climate.** — Мне потребовались месяцы, чтобы привыкнуть к климату.
- **You'll get used to it.** — Ты к этому привыкнешь.

> [!tip] Время меняется в be / get
> **I was used to…** — я был привычен. **I got used to…** — я привык (в прошлом). **I'll get used to…** — привыкну.

> [!warning] Частые ошибки
> - ~~He isn't used to speak English.~~ → **He isn't used to speaking English.** — после `to` здесь `-ing`.
> - ~~I used to drink milk~~ (если имеешь в виду «привык») → **I'm used to drinking milk.**

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Вставь глагол: I'm used to ___ (wake) up early.
2. Выбери: It took me months to (be / get) used to the climate.
3. Выбери: Don't worry, she (is used to / used to) working at night.
4. Выбери: I (used to / am used to) drink milk, but now I don't.
5. Исправь ошибку: *He isn't used to speak English.*
6. Переведи: «Ты к этому привыкнешь».

> [!success]- Ответы и пояснения
> 1. **waking** — после «привык к» нужна форма `-ing`.
> 2. **get** — «месяцы привыкания» — это процесс.
> 3. **is used to** — ей уже привычно, а дальше `working` с `-ing`.
> 4. **used to** — «раньше пил, а теперь нет»; дальше начальная форма `drink`.
> 5. **He isn't used to speaking English.** — после `be used to` — `-ing`.
> 6. **You'll get used to it.** — привыкание в будущем → `will get used to`.
