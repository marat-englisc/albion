# Like, love, want и would like

> [!abstract] Коротко
> **I like coffee** — мне нравится кофе (вообще). **I'd like a coffee** — я бы хотел кофе (сейчас). **Would like** — вежливое «хочу».

## Суть

Эти глаголы делятся на две группы:

| Нравится (вообще) | Хочу (сейчас или скоро) |
| --- | --- |
| **like** — нравится | **want** — хочу (прямо) |
| **love** — очень нравится, обожаю | **would like** (**I'd like**) — хотел бы (вежливо) |

**I want** звучит прямо, почти по-детски. В кафе, магазине, с незнакомыми лучше говорить **I'd like** — как русское «я бы хотел».

## Что ставить после

> [!example] Формула
> **like / love** + **-ing**: I like **swimming**.
>
> **want / would like** + **to** + глагол: I'd like **to leave**.
>
> **would like** + вещь: I'd like **some tea**.

После **like / love** можно и **to**: **I like to swim** — тоже верно.

## Примеры

- **Do you like coffee?** — Ты любишь кофе? *Вообще.*
- **Would you like some coffee?** — Хочешь кофе? *Предлагаю сейчас.*
- **My dad loves cooking.** — Мой папа обожает готовить.
- **I want to sleep.** — Я хочу спать.
- **I'd love to come!** — С удовольствием приду!

> [!tip] Как ответить на предложение
> **Would you like some tea?** → **Yes, please.** / **No, thank you.** Это самый естественный ответ.

> [!warning] Частые ошибки
> - ~~I like a glass of water, please.~~ → **I'd like a glass of water, please.** — просьба сейчас.
> - ~~I'd like going.~~ → **I'd like to go.**
> - ~~I want go.~~ → **I want to go.** — после `want` нужен `to`.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Выбери: (I like / I'd like) a glass of water, please.
2. Выбери: (I like / I'd like) reading detective stories. Это моё хобби.
3. Вставь форму: My dad loves ___ (cook).
4. Вставь форму: I'd like ___ (book) a table for two.
5. Сделай вопрос: *She likes football.*
6. Исправь ответ на предложение: *Would you like some tea? — Yes, I would like.*

> [!success]- Ответы и пояснения
> 1. **I'd like** — вежливая просьба прямо сейчас.
> 2. **I like** — хобби, то, что нравится вообще.
> 3. **cooking / to cook** — после `love` можно оба варианта.
> 4. **to book** — после `would like` нужен `to` + глагол.
> 5. **Does she like football?** — `like` — обычный глагол, вопрос через `does`.
> 6. **Yes, please.** — так отвечают на предложение. `I would like` без продолжения звучит оборванно.
