# Like, love, want и would like

> [!abstract] Коротко
> **Like/love** выражают симпатию или удовольствие: «нравится / люблю». **Want / would like** выражают желание: «хочу / хотел(а) бы»; `would like` обычно звучит вежливее. Желание может относиться и к настоящему, и к будущему.

| Модель | Пример |
| --- | --- |
| like / love + глагол с -ing или to + начальная форма | I like swimming / to swim. |
| want + to + начальная форма | I want to leave. |
| would like + to + начальная форма | I'd like to leave. |
| would like + предмет | I'd like some tea. |

`Like doing` часто подчёркивает удовольствие, `like to do` — привычку или предпочтение. Во многих случаях оба варианта возможны.

## Примеры

- **Do you like coffee?** — Ты любишь кофе вообще?
- **Would you like some coffee?** — Хочешь кофе сейчас?
- **I'd love to come.** — Я с удовольствием приду.

> [!warning] После would like — to
> **I'd like to go**, а не *I'd like going* в значении желания.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Выбери: (I like / I'd like) a glass of water, please.
2. Выбери: (I like / I'd like) reading detective stories. Это моё хобби.
3. Вставь форму: My dad loves ___ (cook).
4. Вставь форму: I'd like ___ (book) a table for two.
5. Сделай вопрос: *She likes football.*
6. Исправь ответ на предложение: *Would you like some tea? — Yes, I would like.*

> [!success]- Ответы и пояснения
> 1. **I'd like** — вежливая просьба сейчас.
> 2. **I like** — постоянный вкус.
> 3. **cooking / to cook** — после `love` допустимы обе формы; `-ing` часто выделяет удовольствие от занятия.
> 4. **to book** — после `would like` нужно `to + начальная форма`.
> 5. **Does she like football?** — `like` — обычный глагол, вопрос через `does`.
> 6. **Yes, please.** — на предложение отвечают `Yes, please`; фраза *I would like* без продолжения неполная.
