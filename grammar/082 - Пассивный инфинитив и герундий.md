# Пассивный инфинитив и герундий

> [!abstract] Коротко
> **To be done / being done** — действие направлено на получателя. Форму выбирает главное слово или предлог.

| Форма | Пример |
| --- | --- |
| to be + третья форма: пассивный инфинитив | want to be invited — хотеть, чтобы тебя пригласили |
| being + третья форма: пассивный герундий | dislike being interrupted — не любить, когда тебя перебивают |
| to have been + третья форма: более раннее действие в пассиве | seem to have been invited — кажется, уже получил приглашение |
| having been + третья форма: более раннее действие в пассиве | mention having been invited — упомянуть, что тебя пригласили |

## Примеры

- **She wants to be heard.** — Она хочет, чтобы её услышали.
- **I object to being treated like a child.** — Я против того, чтобы со мной обращались как с ребёнком.
- **He seems to have been invited.** — Кажется, его пригласили: приглашение было раньше.

Сравни с активными формами: **He seems to have left** — «Кажется, он уехал»; **He admitted having made a mistake** — «Он признался, что совершил ошибку». Сочетание `have/having + третья форма` показывает более раннее действие; для пассива дополнительно нужно `been`.

> [!warning] Два выбора
> Сначала выбери **to / -ing** по модели слова. Затем — актив или пассив по смыслу: **I enjoy helping / being helped**.

**The windows need cleaning = need to be cleaned**: после `need` форма `-ing` может иметь пассивный смысл.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Вставь форму: Nobody likes ___ (lie) to.
2. Вставь форму: She hopes ___ (choose) for the team.
3. Вставь форму: He seems ___ (forget) about our meeting.
4. Перефразируй: *The windows need to be cleaned.* → The windows need ___
5. Выбери: I don't like (to tell / being told) what to do.
6. Исправь ошибку: *This letter must to be sent today.*

> [!success]- Ответы и пояснения
> 1. **being lied / to be lied** — после `like` возможны и герундий, и инфинитив. Полностью: **Nobody likes being lied to / Nobody likes to be lied to** — «Никому не нравится, когда ему лгут». Предлог `to` сохраняется в обеих моделях.
> 2. **to be chosen** — её выберут → пассивный инфинитив.
> 3. **to have forgotten** — кажется сейчас, забыл раньше.
> 4. **The windows need cleaning.** — `need + глагол с -ing` с пассивным смыслом.
> 5. **being told** — мне говорят → пассив.
> 6. **This letter must be sent today.** — после `must` без `to`.
