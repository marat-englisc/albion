# Passive Voice во временах и с модальными глаголами

> [!abstract] Коротко
> - Время показывает `be`, смысловой глагол всегда в `V3`.
> - `is being done` — делают сейчас; `has been done` — уже сделали; `will be done` — сделают; `can/must be done` — можно/нужно сделать.
> - `being` (процесс) ≠ `been` (Perfect).

<!-- beginner-intro:start -->
## Простыми словами

Пассив сохраняет различия времён: что-то делают обычно, делали вчера, делают сейчас или уже сделали. Меняется **цепочка помощников**, а третья форма действия остаётся в конце. Не нужно заново изобретать смысл каждого пассивного времени.

Сначала реши, какой смысл времени нужен. Потом используй соответствующую строку таблицы. Для процесса нужен `being`, для Perfect — `been`. Отрицание и вопрос затрагивают только первый помощник; остальные части сохраняют порядок.

## Правило и схема
<!-- beginner-intro:end -->

В пассиве сохраняется смысл времени: процесс, результат или событие. Меняется цепочка вспомогательных глаголов перед неизменным `V3`.

| Время / конструкция | Схема |
| --- | --- |
| Present Simple | am/is/are + V3 |
| Past Simple | was/were + V3 |
| Present Continuous | am/is/are being + V3 |
| Past Continuous | was/were being + V3 |
| Present Perfect | have/has been + V3 |
| Past Perfect | had been + V3 |
| Будущее | will be + V3 |
| Модальный глагол | can/must/should + be + V3 |
| Модальная оценка прошлого | should/might + have been + V3 |

Отрицание ставится после первого вспомогательного; в вопросе первый вспомогательный идёт перед подлежащим.

<!-- beginner-examples:start -->
## Примеры с разбором

1. **The room is being cleaned.** — Комнату сейчас убирают.  
   **Разбор:** процесс идёт сейчас: `is being + cleaned`.
2. **The room has been cleaned.** — Комнату уже убрали.  
   **Разбор:** сообщаем о результате к настоящему: `has been + cleaned`.
3. **The room will be cleaned tomorrow.** — Комнату уберут завтра.  
   **Разбор:** будущее выражено `will be`; конечное `cleaned` не меняется.
4. **Can this file be deleted?** — Этот файл можно удалить?  
   **Разбор:** после модального `can` нужен `be + V3`; для вопроса выносим только `can`.
<!-- beginner-examples:end -->

## Дополнительные примеры

- **The road is being repaired.** — Дорогу сейчас ремонтируют.
- **Has the parcel been delivered?** — Посылку доставили?
- **The form must be signed.** — Форму необходимо подписать.

> [!warning] Частая ошибка
> **Is being painted** — красят сейчас; **has been painted** — уже покрасили. `Being` и `been` не взаимозаменяемы.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Перестрой в пассив: *They are building a new bridge.*
2. Перестрой в пассив: *Someone has cleaned the room.*
3. Перестрой в пассив: *They will announce the results tomorrow.*
4. Перестрой в пассив: *You must sign this form.*
5. Сделай вопрос: *The parcel has been delivered.*
6. Исправь ошибку: *The house is been painted at the moment.*

> [!success]- Ответы и пояснения
> 1. **A new bridge is being built.** — Present Continuous → `is being + V3`.
> 2. **The room has been cleaned.** — Present Perfect → `has been + V3`.
> 3. **The results will be announced tomorrow.** — будущее → `will be + V3`.
> 4. **This form must be signed.** — модальный → `must be + V3`.
> 5. **Has the parcel been delivered?** — вперёд выходит первый помощник `has`.
> 6. **The house is being painted at the moment.** — процесс сейчас → `being`.
