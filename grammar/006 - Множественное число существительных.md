# Множественное число существительных

> [!abstract] Коротко
> Обычно «несколько» = существительное **+ -s**: **book → books**. Неправильные формы нужно запомнить.

| Как меняется слово | Пример |
| --- | --- |
| обычно после -s, -sh, -ch, -x, -z добавляем -es | bus → buses; box → boxes; quiz → quizzes |
| согласная + y: -ies | baby → babies |
| гласная + y: + -s | boy → boys |
| у части слов -f/-fe: -ves | knife → knives; но roof → roofs |
| особые формы | child → children; woman → women; person → people |
| без изменения | sheep → sheep; fish → fish — обычно |

После `-ch` со звуком /k/ обычно добавляется только `-s`: **stomach → stomachs**.

Окончание `-o` проверяй: **potatoes**, но **photos**. `Trousers` и `scissors` — множественное число; одна вещь — **a pair of scissors**.

> [!warning] Без апострофа
> **Two photos**, а не *two photo's*.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Образуй множественное число: *dish*
2. Образуй множественное число: *baby*
3. Образуй множественное число: *knife*
4. Образуй множественное число: *woman*
5. Исправь ошибку: *I have two childs.*
6. Исправь ошибку: *These are my new photo's.*

> [!success]- Ответы и пояснения
> 1. **dishes** — после `-sh` добавляем `-es`.
> 2. **babies** — согласная + `y` → `-ies`.
> 3. **knives** — `-fe` у этого слова превращается в `-ves`.
> 4. **women** — неправильная форма, её нужно запомнить.
> 5. **I have two children.** — `child` имеет особую форму множественного числа.
> 6. **These are my new photos.** — апостроф не образует множественное число.
