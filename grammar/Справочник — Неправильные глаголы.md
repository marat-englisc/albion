# Справочник — Неправильные глаголы

> [!abstract] Как пользоваться
> - Три формы: **V** (начальная) — **V2** (Past Simple) — **V3** (причастие для Perfect и пассива).
> - Учи не по алфавиту, а **по группам с одинаковым рисунком**: так запоминается в несколько раз быстрее.
> - Начни с отмеченных ⭐ — это самые частые глаголы уровня A1–A2. Где даны две формы через `/`, обе верны; первая — более британская.

Как формы используются: V2 — [[028 - Past Simple — завершённое прошлое|Past Simple]]; V3 — [[033 - Present Perfect — связь прошлого с настоящим|Present Perfect]] и [[067 - Passive Voice — основа пассивного залога|пассив]]. Все рабочие формы глагола: [[016 - Формы глагола и окончания -s, -ed, -ing|Формы глагола и окончания]].

## Ловушки

| Пара | Разница |
| --- | --- |
| **lie — lay — lain** / **lie — lied — lied** | лежать / лгать (правильный глагол) |
| **lay — laid — laid** | класть, накрывать (`lay the table`) |
| **find — found — found** / **found — founded — founded** | находить / основывать |
| **fall — fell — fallen** / **feel — felt — felt** | падать / чувствовать |
| **hang — hung — hung** / **hang — hanged — hanged** | вешать предмет / казнить через повешение |
| **rise — rose — risen** / **raise — raised — raised** | подниматься (сам) / поднимать (что-то) |
| **leave — left — left** / **live — lived — lived** | уходить / жить |

> [!tip] Как учить
> По 10 глаголов в день из одной группы. Проговаривай вслух ритмом: «drink — drank — drunk, sing — sang — sung, swim — swam — swum». Затем составь с каждым глаголом одно предложение в Past Simple и одно в Present Perfect.
