# Сравнительная степень — bigger и more useful

> [!abstract] Коротко
> Чтобы сравнить две вещи: короткое слово + **-er** (**bigger**), длинное — **more** + слово (**more useful**). «Чем» — **than**: **This bag is cheaper than that one.**

## Суть

В русском тоже два способа: «**умнее**» и «**более** умный». В английском выбор зависит от **длины слова**:

| Слово | Как | Пример |
| --- | --- | --- |
| **короткое** (1 слог) | **+ er** | small → small**er**, cheap → cheap**er** |
| короткое, гласная + согласная | удвой букву + er | big → bi**gg**er, hot → ho**tt**er |
| кончается на **-y** | **y → ier** | happy → happ**ier**, easy → eas**ier** |
| **длинное** (2–3 слога и больше) | **more** + слово | **more** useful, **more** expensive |

> [!example] Формула
> **A** + **is** + **-er / more…** + **than** + **B**
>
> My brother **is taller than** me.

## Исключения

Их всего несколько, но они очень частые:

- **good → better** — хороший → лучше
- **bad → worse** — плохой → хуже
- **far → farther / further** — далёкий → дальше

## Меньше, а не больше

Для «менее» — **less**: **This option is ==less== expensive.** — Этот вариант менее дорогой.

## Примеры

- **This bag is cheaper than that one.** — Эта сумка дешевле той.
- **Today is hotter than yesterday.** — Сегодня жарче, чем вчера.
- **This chair is more comfortable.** — Этот стул удобнее.
- **The journey is much longer.** — Поездка намного длиннее. *«Намного» — `much`, не `very`.*

> [!tip] Только один способ
> Либо **-er**, либо **more** — никогда оба сразу: ~~more better~~, ~~more easier~~.

> [!warning] Частые ошибки
> - ~~more tall~~ → **taller** — короткое слово → `-er`.
> - ~~more easier then~~ → **easier than** — один способ; «чем» — `than` (не `then` — «потом»).
> - ~~usefuler~~ → **more useful**

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Образуй сравнительную степень: *hot*
2. Образуй сравнительную степень: *easy*
3. Образуй сравнительную степень: *comfortable*
4. Образуй сравнительную степень: *bad*
5. Исправь ошибку: *My brother is more tall than me.*
6. Исправь ошибку: *This exercise is more easier then that one.*

> [!success]- Ответы и пояснения
> 1. **hotter** — одна гласная + одна согласная → удваиваем `t`.
> 2. **easier** — кончается на `-y` → `-ier`.
> 3. **more comfortable** — длинное слово → `more`.
> 4. **worse** — исключение.
> 5. **My brother is taller than me.** — `tall` короткое → `-er`.
> 6. **This exercise is easier than that one.** — один способ сравнения; «чем» — `than`.
