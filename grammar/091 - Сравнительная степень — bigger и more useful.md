# Сравнительная степень — bigger и more useful

> [!abstract] Коротко
> - Короткие слова: `+ -er than` — `cheap → cheaper than`, `big → bigger`, `happy → happier`.
> - Длинные: `more + adj + than` — `more expensive than`. Меньше: `less + adj`.
> - Неправильные: `good → better`, `bad → worse`, `far → further/farther`. *more better* — ошибка.

<!-- beginner-intro:start -->
## Простыми словами

Сравнительная степень означает «больше по какому-то признаку»: выше, дешевле, интереснее. Сначала реши, какой признак сравниваешь, затем образуй его сравнительную форму. Второй предмет вводится через `than` — «чем».

У коротких слов часто добавляется `-er`, у длинных ставится `more`. Не используй оба способа одновременно. Особые формы `better/worse` учим отдельно: в них уже есть смысл «лучше/хуже», поэтому дополнительное `more` не нужно.

## Правило и схема
<!-- beginner-intro:end -->

Сравнительная степень показывает различие между людьми, предметами и ситуациями. Второй объект вводится через `than`.

| Тип | Образование |
| --- | --- |
| Короткое прилагательное | small → smaller; nice → nicer |
| Краткая гласная + согласная | big → bigger |
| Согласная + -y | happy → happier |
| Длинное, большинство прочих | more useful, more expensive |
| Неправильные | good → better; bad → worse; far → farther/further |

`Less + adj` означает меньшую степень: `less expensive`. Некоторые двусложные слова допускают оба варианта: `simpler / more simple`. Для сравнения одинаковых качеств: [[093 - Равенство и усиление сравнений|Равенство и усиление сравнений]].

<!-- beginner-examples:start -->
## Примеры с разбором

1. **This street is quieter than ours.** — Эта улица тише нашей.  
   **Разбор:** `quiet → quieter`; `than` вводит второй объект сравнения.
2. **This course is more expensive.** — Этот курс дороже.  
   **Разбор:** длинное `expensive` получает `more`, а не окончание `-er`.
3. **Today is better than yesterday.** — Сегодня лучше, чем вчера.  
   **Разбор:** `better` — готовая неправильная форма от `good`; `more better` не подходит.
4. **The bus is less comfortable than the train.** — Автобус менее удобен, чем поезд.  
   **Разбор:** `less` показывает меньшую степень качества; само `comfortable` не меняется.
<!-- beginner-examples:end -->

## Дополнительные примеры

- **This room is larger than mine.** — Эта комната больше моей.
- **The second task is more difficult.** — Второе задание сложнее.
- **I feel better today.** — Сегодня я чувствую себя лучше.

> [!warning] Частая ошибка
> **Better**, а не *more better*. **Than** вводит сравнение; **then** означает «тогда, затем».

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Образуй сравнительную степень: *hot*
2. Образуй сравнительную степень: *easy*
3. Образуй сравнительную степень: *comfortable*
4. Образуй сравнительную степень: *bad*
5. Исправь ошибку: *My brother is more tall than me.*
6. Исправь ошибку: *This exercise is more easier then that one.*

> [!success]- Ответы и пояснения
> 1. **hotter** — краткая гласная + согласная → удвоение.
> 2. **easier** — согласная + `y` → `-ier`.
> 3. **more comfortable** — длинное слово → `more`.
> 4. **worse** — неправильная форма.
> 5. **My brother is taller than me.** — короткое слово → `-er`.
> 6. **This exercise is easier than that one.** — одна форма сравнения; «чем» — `than`, не `then`.
