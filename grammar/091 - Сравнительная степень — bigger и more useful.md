# Сравнительная степень — bigger и more useful

> [!abstract] Коротко
> Для сравнения двух объектов: **smaller / more useful + than** — меньше / полезнее, чем.

| Тип слова | Сравнение |
| --- | --- |
| большинство односложных прилагательных: + -er | small → smaller; nice → nicer |
| короткая гласная + согласная | big → bigger |
| многие двусложные прилагательные на согласную + y: -ier | happy → happier |
| большинство остальных прилагательных: more + обычная форма | more useful / expensive |
| особые формы | good → better; bad → worse; far → farther/further |

## Примеры

- **This bag is cheaper than that one.** — Эта сумка дешевле той.
- **This option is less expensive.** — Этот вариант менее дорогой.
- **The journey is much longer.** — Поездка намного дольше.

> [!warning] Один способ сравнения
> **Better**, а не *more better*; **more useful**, а не *usefuler*. Некоторые двусложные слова допускают оба способа: **simpler / more simple**.

## Проверь себя

Сначала ответь сам, потом открой ответы: нажми на заголовок блока.

1. Образуй сравнительную степень: *hot*
2. Образуй сравнительную степень: *easy*
3. Образуй сравнительную степень: *comfortable*
4. Образуй сравнительную степень: *bad*
5. Исправь ошибку: *My brother is more tall than me.*
6. Исправь ошибку: *This exercise is more easier then that one.*

> [!success]- Ответы и пояснения
> 1. **hotter** — краткая гласная + согласная → удвоение.
> 2. **easier** — согласная + `y` → `-ier`.
> 3. **more comfortable** — длинное слово → `more`.
> 4. **worse** — неправильная форма.
> 5. **My brother is taller than me.** — короткое слово → `-er`.
> 6. **This exercise is easier than that one.** — одна форма сравнения; «чем» — `than`, не `then`.
