# Albion — British English

Android-приложение для изучения английского: карточки с интервальным повторением FSRS-6 и учебник грамматики.

**Стек:** Kotlin · Jetpack Compose · Material 3 · Navigation 3 · Room · Preferences DataStore · Media3 ExoPlayer.

## Разделы

| Раздел | Что внутри |
| --- | --- |
| Слова, Фразовые глаголы, Идиомы, Коллокации | Лицевая сторона: слово, транскрипция, часть речи, озвучка. Оборот: то же + значение EN/RU и 2 примера (изучаемое слово выделено). Сиблинги: значения одного слова (take off — «взлетать», «снимать») не показываются в один день — второе ждёт следующего, чтобы не подсказывать первое. |
| Неправильные глаголы | V1/V2/V3 со всеми вариантами (abided / abode), транскрипцией и озвучкой каждой формы, по 3 примера на форму, примечание. |
| Грамматика | Учебник из Obsidian-заметок: главы, уровни A1–C1, поиск, закладки, «Продолжить», отметки «изучено», раскрывающиеся ответы, схемы Mermaid, адаптивные таблицы (широкие на телефоне превращаются в карточки), переходы по [[ссылкам]], размер текста. В конце каждой темы — «Проверь себя»: все задания по ней из `grammar_tasks.xlsx` (выбор и ввод вперемешку); 70% и выше — тема отмечается изученной. |
| Игры | «Ввод ответа» (слово по русскому значению, опечатки как «почти», подсказки по буквам), «Неправильные глаголы» (впишите V2 и V3, повтор ошибок), «Шэдоуинг» (диктор, в том числе замедленно → своя запись, которая останавливается сама → разбор на устройстве: сходство с диктором, интонация, ритм и темп, график мелодики «диктор / вы» и советы — про темп, монотонность, тон в конце фразы и ударение), «Произношение» (встроенное распознавание речи Android, офлайн при скачанном пакете английского), «Грамматика» (выбор верного варианта) и «Допиши пропуск» (вписать форму сами) — 794 задания из `grammar_tasks.xlsx` по всем темам учебника, A1–C1, с пояснением и ссылкой на правило; задания с ошибками попадаются чаще. «Собери предложение» — слова примера из карточки нужно расставить по порядку; идиома или коллокация остаётся одной плашкой, длинные примеры сокращаются до части с выражением. «Тренажёр времён» — примеры из таблицы неправильных глаголов с пропуском (≈1650 заданий): выбрать или вписать V1/V2/V3, после ответа — правило по окружению (have + V3, had + V3, пассив, после did/to/модального — V1) и все формы с озвучкой. Игры запоминают ошибки по словам (отдельно для каждой игры): такие слова попадаются первыми, есть режим «Только ошибки»; слово уходит из ошибок после двух верных ответов подряд. В «Вводе ответа» идиомы с подстановками принимаются в любом виде: someone / sb / «drive me up the wall», someone's / «catch his eye». На FSRS не влияют. |
| Библиотека | Читалка со страницами: касание слова — перевод (Google ML Kit, на устройстве) и справка из ваших карточек; долгое нажатие — перевод предложения; долгое нажатие с протягиванием — любой фрагмент. Закладки, оглавление, место чтения, размер шрифта. **Выделения и заметки**: в окне перевода — «Выделить» / «Заметка», в тексте — мягкий маркер, список всех выделений с переходом к месту. **Мои слова**: слова и выражения из начатых, но ещё не выученных карточек подчёркнуты пунктиром — с учётом форм (went → go, gave up → give up); выключается в меню размера текста. Встроена книга-пример «The Keeper of Gull Island» (B1); свои книги — TXT, MD, EPUB или PDF (текстовый; сканы без распознавания текста не поддерживаются) через «Добавить книгу» или папку `library`. |
| Статистика | Серия дней, удержание, повторения за 30 дней, прогноз, разбивка по колодам. |
| Настройки | Дневная цель и ежедневное напоминание (время, «только если есть что повторить», пробное уведомление), подстройка FSRS под вашу память по истории ответов, тема (тёмная, светлая, как в системе), русское значение на обороте вкл/выкл, желаемое удержание FSRS, лимиты в день, порядок новых карточек (по CEFR), автоозвучка, скорость. |

Занятие устроено как в Anki: учебные шаги 1 и 10 мин, затем интервалы FSRS в днях; кнопки «Снова / Трудно / Хорошо / Легко» показывают будущий интервал; есть отмена ответа.

**Подстройка FSRS.** По журналу ответов приложение заново прогоняет модель памяти FSRS-6 и подбирает 21 параметр (Adam, мягкая привязка к текущим значениям). Нужно минимум 150 повторений с интервалом от суток. Последние 20% повторений по времени откладываются для независимой проверки и не участвуют в подборе. Новые параметры применяются, только если ошибка на этой истории ниже ошибки текущих параметров хотя бы на 0,1%. Если историю нельзя разделить или улучшения нет, текущие параметры сохраняются. Если параметры изменились или были сброшены во время подбора, его результат не применяется.

**Сохранение ответов.** Состояние карточки и запись журнала сохраняются одной транзакцией Room; отмена ответа также атомарна. При ошибке записи изменения откатываются, карточка остаётся на экране и ответ можно повторить.

## Материалы

Материалы берутся из папки над проектом (`../collections`, `../audio`, `../grammar`) и **вшиваются при сборке**:

```properties
# gradle.properties
albion.bundleContent=true   # по умолчанию: всё вшито, после установки ничего докачивать не нужно
albion.contentDir=..        # где лежат collections/, audio/, grammar/
```

Для быстрых экспериментов с кодом можно собрать «пустое» приложение: `./gradlew assembleDebug -Palbion.bundleContent=false`. Если при сборке с материалами папки `collections` нет, сборка остановится с понятной ошибкой — пустой APK случайно не получится.

- `grammar_tasks.xlsx` — задания по грамматике: № · Уровень · Номер темы · Тема · Тип (выбор/ввод) · Задание (пропуск — `___`) · Вариант 1–4 · Правильный ответ (для ввода — варианты через « / ») · Пояснение. Новые строки можно дописывать прямо в Excel.
- `library/` — книги (`.txt`, `.md`, `.epub`, `.pdf`), вшиваются вместе с материалами. Формат MD: `# Название`, строки `Author:` и `Level:`, главы `## …`, абзацы через пустую строку.
- Импорт книг: файл до **30 МБ**, текст до **5 млн символов**; TXT/MD — UTF-8 или UTF-16 с BOM. EPUB читается XML-парсером с учётом кодировки, пространств имён, относительных путей и порядка глав; распаковка ограничена 64 МБ и 4096 файлами, текстовые ресурсы — 16 МБ суммарно и 8 МБ на раздел. PDF — до 2000 страниц, с текстовым слоем и без пароля. Повторный импорт открывает уже добавленную книгу и сохраняет место чтения, закладки и заметки. Встроенные книги обновляются по контрольной сумме, включая изменения того же размера. Файлы текста сохраняются через AtomicFile; ошибка добавления записи в базу не оставляет новую книгу в библиотеке.
- Перевод в библиотеке работает в два слоя:
  - **слова** — встроенный офлайн-словарь EN → RU (`app/src/main/assets/dictionary/eng-rus.tsv`, ~62 тыс. статей из FreeDict/Викисловаря, лицензия CC BY-SA 3.0 — `dictionary/LICENSE.txt`). Работает сразу после установки, без сети; понимает формы (studied → study, went → go — неправильные формы берутся из колоды неправильных глаголов);
  - **фразы** — Google ML Kit. Google не разрешает класть модель (~30 МБ) в APK, поэтому приложение само скачивает её в фоне при первом запуске (или как только появится сеть). Пока модели нет, фрагмент разбирается по словам встроенным словарём.
- Что всё-таки зависит от системы: проверка произношения использует системное распознавание речи Google (нужен офлайн-пакет en-GB или сеть); TTS озвучивает только то, для чего нет mp3.
- Колонки xlsx ищутся по заголовкам («IPA», «Значение на русском», «Пример 1»…), порядок колонок можно менять.
- Озвучка: `audio/<колода>/<термин>.mp3`; омонимы с уточнением в скобках (`March (month)`, `read (past)`, `ate (eit)` — альтернативное произношение). Нет файла — озвучит системный TTS (en-GB).
- После правки таблиц просто пересоберите: приложение заметит изменения и обновит карточки, **прогресс сохранится** (id карточки = колода + термин + номер значения).

## Сборка и тесты

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest   # FSRS, разбор ваших xlsx + озвучки, все темы грамматики
./gradlew connectedDebugAndroidTest   # на эмуляторе/устройстве: откат записи и отмены при сбоях, безопасный подбор FSRS
```

Release-сборка подписана debug-ключом для личной установки — замените `signingConfig` перед публикацией.
